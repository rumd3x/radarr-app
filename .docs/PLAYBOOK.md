# Playbook

Operational notes. This app was cloned from `sonarr-app` (the reference implementation); the generic recipe, pipeline details and Play Console steps are documented in `../sonarr-app/.docs/PLAYBOOK.md`.

## Environment
- Flutter via snap; build with JDK 17: `JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64 flutter build apk --debug` (JDK 25 breaks Gradle).
- `android/app/build.gradle.kts` `namespace` and `applicationId` = `com.rumd3x.radarr`; `MainActivity.kt` lives in `android/app/src/main/kotlin/com/rumd3x/radarr/`. The Application ID must match the package created in Play Console.

- After builds run `(cd android && ./gradlew --stop)`. The Gradle daemon holds ~4.5 GB and can make the emulator freeze ("Emulator not responding").
- Emulator: AVD `radarr_pixel` (Pixel 7, `android-35;google_apis;x86_64`), KVM available, no sudo needed. Create it with `avdmanager create avd -n radarr_pixel -k "system-images;android-35;google_apis;x86_64" -d pixel_7`, then set `hw.ramSize = 2048` and `hw.cpu.ncore = 3` in `~/.android/avd/radarr_pixel.avd/config.ini`. Stable flags: `emulator -avd radarr_pixel -gpu host -no-snapshot -no-boot-anim`. adb: `~/Android/Sdk/platform-tools/adb`. From the emulator the host machine is **`10.0.2.2`**.
- **Always use the `radarr_pixel` AVD for this app** (`flutter emulators --launch radarr_pixel`, then `flutter run -d emulator-5554`). Never launch `sonarr_pixel` or `lidarr_pixel`: they belong to the sibling apps and may be in use. Confirm with `adb -s emulator-5554 emu avd name`.
- Rebuild the APK after regenerating launcher icons (`dart run flutter_launcher_icons`), otherwise the installed app shows stale icons.

## Release / Google Play
- Same Jenkins pipeline and credentials as the sibling apps (`jenkins-app-release/release.groovy`): signing via `android/key.properties`, version bump through `./gradlew updateVersion`, publish with the Gradle Play Publisher plugin. Listing texts: `android/app/src/main/play/listings/en-US/`. Graphics: `python3 scripts/generate_play_assets.py` (needs Pillow).
- Play Console "App access": no login exists; instruct reviewers to tap **Try demo** on the Setup screen.

## Screenshots (manual)
Use the app's own demo mode (tap **Try demo**; no mock server needed), so only the setup screen is shot before tapping it.
- Run on the `radarr_pixel` AVD only. Install the freshly built APK, then `adb exec-out screencap -p > file.png` (1080×2400). Tap coordinates are in device pixels (check `adb shell wm size`; viewers may downscale).
- Don't type into the setup form with `adb input text` (it drops characters).
- **Google Play needs aspect ratio ≤ 2:1.** Crop the emulator border (4 px) and pad the sides with the app's background colour to 1196×2392 (Pillow).
- Never generated by the pipeline or `scripts/generate_play_assets.py`; committed to `assets/images/screenshots/NN-name.png` (01 setup, 02 movies, 03 movie detail, 04 manual search, 05 calendar, 06 activity, 07 wanted, 08 more), which the release pipeline reads. Retake when the UI changes and keep the `README.md` references in sync.
- Delete temp files afterwards.
